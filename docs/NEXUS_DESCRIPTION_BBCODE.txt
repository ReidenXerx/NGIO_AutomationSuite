[size=5][b][color=#f1c84b]What it is[/color][/b][/size]

[url=https://www.nexusmods.com/skyrimspecialedition/mods/42161]No Grass In Objects[/url] (NGIO) makes grass load fast and draw far. To do that it needs a grass cache, a set of files that remember where grass grows.

Making that cache is the slow part. Skyrim has to visit every cell of every worldspace. It takes hours, and the game crashes along the way. With [url=https://www.nexusmods.com/skyrimspecialedition/mods/62861]Seasons of Skyrim[/url] you do it four times, once per season.

This tool does that loop for you. Pick the seasons, go to bed, and install the archives in the morning. It is a single [font=Courier New].exe[/font] for Windows, with nothing to install and no Python to set up.

[center][img]https://cdn.jsdelivr.net/gh/ReidenXerx/NGIO_AutomationSuite@fd8badf4de7a8e32f86e9af548ce685937da57c1/docs/img/cards.jpg[/img][/center]

[size=5][b][color=#f1c84b]What you get[/color][/b][/size]

[list]
[*][b]Overnight Mode.[/b] Option 5, [i]All 4 Seasons[/i], runs Winter, Spring, Summer and Autumn back to back. The tool's own estimate is 4 to 6 hours; a large load order takes longer.[/*]
[*][b]Crash recovery.[/b] When Skyrim dies, the tool notices within about 10 seconds and launches it again. If the game makes no progress for 15 minutes, that counts as a crash too. It retries 10 times per season by default.[/*]
[*][b]Ready-made mods.[/b] Every season is packed as its own archive, like [font=Courier New]Grass_Cache_Winter_Season.zip[/font]. A FOMOD installer and a SHA-256 checksum (a fingerprint that proves the file is intact) come with it. Install it with Vortex or MO2 like any other mod.[/*]
[*][b]Runs on a schedule.[/b] [font=Courier New]--season all --unattended[/font] asks no questions, so Windows Task Scheduler can start it.[/*]
[*][b]Checks first.[/b] Before a run it checks RAM, pagefile and free disk space, and tells you what to change if one is short.[/*]
[*][b]LOD grass for DynDOLOD (optional).[/b] Say yes at setup and it also packs one season's cache without the season name, as [font=Courier New]Grass_Cache_Default_LOD.zip[/font]. DynDOLOD's grass LOD reads that one.[/*]

[size=5][b][color=#f1c84b]How it works[/color][/b][/size]

[center][img]https://cdn.jsdelivr.net/gh/ReidenXerx/NGIO_AutomationSuite@fd8badf4de7a8e32f86e9af548ce685937da57c1/docs/img/pipeline.jpg[/img][/center]
[center][i]One pass per season. The same five steps, four times.[/i][/center]

For each season you pick, the tool sets that season, starts Skyrim and lets NGIO build the grass cache. It watches NGIO's progress file to know the game is still working. A long load before the first cell is not mistaken for a hang.

When the pass is done, the cache files are labelled with their season, so the seasonal mod picks the right ones. Then the season is packed as a mod. Without a seasonal mod, choose non-seasonal at setup and you get one plain cache instead.

[size=5][b][color=#f1c84b]Before your first run[/color][/b][/size]

[quote]
[b]1. Give Windows a pagefile of 20 GB or more.[/b]
Skyrim's grass pass can use more memory than you have RAM. The tool calls a pagefile under 10 GB critical and under 20 GB a warning. To set it: [i]System Properties → Advanced → Performance Settings → Advanced → Virtual memory → Change[/i], custom size 20480 MB, then restart.

[b]2. On MO2, launch the tool from inside MO2.[/b]
Add the [font=Courier New].exe[/font] under MO2's Executables and start it from MO2's dropdown. Started from Explorer, it cannot see MO2's virtual files and stops with [i]"Seasons of Skyrim config file not found"[/i]. On Vortex, run it directly.[/quote][size=4][b]Getting started[/b][/size]
[list=1]
[*]Install the requirements: SKSE64 and No Grass In Objects, plus Seasons of Skyrim and Grass Cache Helper NG for seasonal grass.[/*]
[*]Download the [font=Courier New].exe[/font] from the Files tab and put it anywhere.[/*]
[*]Run it, or run it from MO2. The first time, it asks for your Skyrim folder, where to save the archives, and whether you use a seasonal mod. It remembers the answers.[/*]
[*]Pick [b]5[/b] for all four seasons and leave the PC alone.[/*]
[*]In the morning, install the archives from the output folder with your mod manager.[/*]
[/list][center][img]https://cdn.jsdelivr.net/gh/ReidenXerx/NGIO_AutomationSuite@fd8badf4de7a8e32f86e9af548ce685937da57c1/docs/img/divider.png[/img][/center]

[size=5][b][color=#f1c84b]Incompatibilities[/color][/b][/size]

Known conflicts, from real reports and the code. Found another one? Tell us in the Bugs tab.
[list]
[*][b][url=https://www.nexusmods.com/skyrimspecialedition/mods/106440]Trainwreck - A Crash Logger[/url][/b]: its crash popup keeps a crashed game open, so the automatic restart waits until the hang timer runs out. Disable it for grass runs, or expect about 10-15 minutes lost per crash.[/*]
[*][b][url=https://www.nexusmods.com/skyrimspecialedition/mods/31720]Kezyma's Root Builder for Mod Organizer[/url][/b]: it can move PrecacheGrass.txt, so generation starts on every launch or never finishes. Add PrecacheGrass.txt as a Root Builder exclusion (No Grass In Objects' own advice).[/*]
[*][b]Any mod that already ships a grass cache (.cgid files in Data\Grass)[/b]: NGIO skips every cell that already has a file, so those cells keep the old grass. Disable it before generating.[/*]
[*][b]Skyrim VR[/b]: the 1.6.0 exe does not recognise the VR game and reports "no activity". The 2.0 betas start sksevr_loader.exe.[/*]
[*][b]Mod Organizer 2 with the 1.6.0 exe[/b]: started from Explorer it can't see MO2's files ("Seasons of Skyrim config file not found"). Run it from MO2's Executables, or use the 2.0 MO2 plugin.[/*]
[/list][size=5][b][color=#f1c84b]FAQ[/color][/b][/size]

[b]A run keeps crashing at the same place. What helps?[/b]
[spoiler]
What owners of large load orders report working:
[list]
[*]A 20 GB pagefile on an SSD.[/*]
[*]A slim profile in your mod manager for the run: keep the landscape and grass mods, and disable big script-heavy or visual mods you do not need to place grass.[/*]
[*]Windowed mode at 800×600 for the run. The [font=Courier New].cgid[/font] files only record where grass goes, so they do not depend on graphics settings.[/*]
[/list]If it still fails, open a Bugs report with the text from the tool's window. Running it with [font=Courier New]--verbose[/font] adds the detail that helps most.[/spoiler]

[b]Can I run it on a schedule, without the menu?[/b]
[spoiler]
Yes. [font=Courier New]--season all --unattended[/font] runs without questions, which is what Windows Task Scheduler needs. [font=Courier New]--dry-run[/font] tests the setup without launching Skyrim. [font=Courier New]--help[/font] lists the rest.[/spoiler]

[b]Does it work on Steam Deck or Linux?[/b]
[spoiler]
On Linux (Proton, Steam Deck) the notification layer detects Wine and turns itself off, and [font=Courier New]--no-notifications[/font] disables it entirely. Tell us how it goes in the comments.[/spoiler]

[b]Windows warns about an unknown publisher.[/b]
[spoiler]
The [font=Courier New].exe[/font] is a PyInstaller build and is not code-signed, so SmartScreen does not recognise the publisher. It launches Skyrim, watches it and renames thousands of files, which some heuristic scanners also flag. The full source it is built from is on [url=https://github.com/ReidenXerx/NGIO_AutomationSuite]GitHub[/url].[/spoiler]

[b]Do I need to run it again?[/b]
[spoiler]
Only when you change something that places grass: a grass mod, a landscape mod, or the worldspaces themselves. Graphics settings do not matter.[/spoiler]
